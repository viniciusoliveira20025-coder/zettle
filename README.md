# Zettelkasten

Aplicativo de notas no método Zettelkasten (Niklas Luhmann), com numeração ramificada, ligações entre notas, leitor em tela cheia, prints e backup.

## Como usar

1. Abra o endereço do GitHub Pages deste repositório.
2. Instale: no Android/Chrome, menu ⋮ → "Instalar app"; no iPhone/Safari, Compartilhar → "Adicionar à Tela de Início".

## Dados

As notas ficam salvas no navegador do aparelho. Use **Exportar backup** regularmente e guarde o arquivo `.json` em outro lugar. Para restaurar, use **Importar backup**.

## Arquivos

- `index.html`: o aplicativo
- `manifest.json`, `icon.svg`, `icon-192.png`, `icon-512.png`: instalação e ícones
- `sw.js`: funcionamento offline
